### Currently working on

- **Final year project**: a web app that tells independent artists what genre their unreleased music sounds like, and why. I'm comparing an SVM, a CNN and a pretrained music model, and using explainable AI to make the predictions understandable.
- **Motion Stickers**: takes fixed-camera footage, like home CCTV, detects anything that moves and cuts it out as an iPhone-style sticker, laid out on a timeline. Built with classical image processing in OpenCV (frame differencing, thresholding, morphological clean-up, night-time contrast enhancement) and a Streamlit interface, no machine learning. Team project with two classmates.
- **Dumpling Passport**: a mixed-reality cooking game for Meta Quest, built in Godot 4 with OpenXR. Players turn their own room into a kitchen and learn to make dumplings from Poland, Lithuania and the Philippines using hand tracking. Team project with two classmates.
